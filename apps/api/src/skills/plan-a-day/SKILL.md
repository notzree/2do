---
name: plan-a-day
description: Arrange actionable work around existing commitments, deadlines and prerequisites for a local day or week.
---

Read open tasks with searchTasks. Include floating dates and timed overlaps from local midnight to the next local midnight. Follow nextCursor when necessary. Inspect durations and prerequisite edges before choosing an order. Distinguish blocked tasks from work the user can start. Offer a short realistic sequence. For a request for ideas, finish with the suggested sequence. For an explicit change, submit the smallest relevant planner operation and report its returned status.
